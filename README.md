# Rujuta Phaltankar — Portfolio

A responsive personal portfolio for showcasing Rujuta's software engineering and AI projects, technical skills, education, and experience.

## Features

- Light, responsive design with sections for About, Projects, Skills, Journey, and Contact
- Project summaries with technology tags and links to live demos or source code
- Resume dialog with downloadable PDF and Word copies
- No build step or package installation required

## Run locally

Open `index.html` in a browser. Alternatively, serve the project directory with any static file server.

Keep `Rujuta_Phaltankar_Resume.pdf` and `Rujuta_Phaltankar_Resume.docx` alongside `index.html` so the resume download links work.

## Customize

Edit the content and styles directly in `index.html`. Update the project links, contact details, and resume files as needed.
